## 🚀 COMMENT EXECUTER LE PROJET (3 ETAPES)

### 📍 ETAPE 1: Base de Données MySQL

**Option A - MySQL Workbench (RECOMMANDE):**
1. Ouvrez MySQL Workbench
2. Connectez-vous (utilisateur: root)
3. Ouvrez le fichier: `database.sql`
4. Cliquez sur l'icône ⚡ "Execute" (ou Ctrl+Shift+Enter)
5. Vérifiez que la base `gestion_stock` est créée

**Option B - Ligne de commande:**
```cmd
mysql -u root -p < database.sql
```

**Vérification:**
```sql
USE gestion_stock;
SHOW TABLES;  -- Doit afficher: categories, products, users
SELECT COUNT(*) FROM products;  -- Doit afficher: 18
```

---

### 📍 ETAPE 2: Configuration (IMPORTANT)

**Vérifiez le mot de passe MySQL:**
- Ouvrez: `src\dao\dbconnection.java`
- Ligne 8: `private static final String PASSWORD = "";`
- Si votre mot de passe MySQL **N'EST PAS VIDE**, modifiez cette ligne:
  ```java
  private static final String PASSWORD = "votre_mot_de_passe_mysql";
  ```

## 🏗️ ARCHITECTURE TECHNIQUE

### Patrons de Conception Utilisés
1. **MVC** (Model-View-Controller)
   - Séparation claire des responsabilités
   - Model: Entités métier
   - View: Interfaces FXML
   - Controller: Logique applicative

2. **DAO** (Data Access Object)
   - Abstraction de l'accès aux données
   - Séparation logique/persistance

### Principes POO Appliqués

- ✅ **Héritage**: Extends Application
- ✅ **Polymorphisme**: Override de méthodes
- ✅ **Modularité**: Organisation en packages

- **Relations**: Clés étrangères (products → categories)
- **Index**: Sur category_id et name

## ❌ RESOLUTION DES PROBLEMES

### Problème: "Access denied for user 'root'"
**Solution**: Modifiez le mot de passe dans `src\dao\dbconnection.java`

### Problème: "Unknown database 'gestion_stock'"
**Solution**: Importez `database.sql` dans MySQL Workbench

### Problème: "JavaFX runtime components are missing"
**Solution**: Utilisez Maven Wrapper (`.\mvnw.cmd javafx:run`)

### Problème: "ClassNotFoundException: com.mysql.cj.jdbc.Driver"
**Solution**: Maven téléchargera automatiquement le driver lors de la compilation

### Problème: L'application ne démarre pas
**Solution**:
1. Vérifiez que MySQL est démarré
2. Vérifiez les logs dans la console
3. Testez la connexion MySQL manuellement
