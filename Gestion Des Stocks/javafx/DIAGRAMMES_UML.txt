### Description des Cas d'Utilisation

#### CU1 : Se connecter
- **Acteur principal** : Utilisateur
- **Précondition** : L'application est lancée
- **Postcondition** : L'utilisateur est authentifié et accède à l'interface principale
- **Scénario nominal** :
  1. L'utilisateur saisit son nom d'utilisateur
  2. L'utilisateur saisit son mot de passe
  3. Le système vérifie les identifiants
  4. Le système affiche l'interface de gestion des produits

#### CU2 : Consulter liste des produits
- **Acteur principal** : Utilisateur
- **Précondition** : L'utilisateur est connecté
- **Postcondition** : La liste des produits est affichée
- **Scénario nominal** :
  1. Le système récupère tous les produits
  2. Le système affiche les produits dans un tableau
  3. Le système affiche le statut de chaque produit

#### CU3 : Ajouter un produit
- **Acteur principal** : Utilisateur
- **Précondition** : L'utilisateur est connecté
- **Postcondition** : Un nouveau produit est ajouté à la base
- **Scénario nominal** :
  1. L'utilisateur clique sur "Ajouter"
  2. Le système affiche un formulaire
  3. L'utilisateur remplit les informations
  4. L'utilisateur valide
  5. Le système vérifie les données
  6. Le système enregistre le produit
  7. Le système actualise la liste

#### CU4 : Modifier un produit
- **Acteur principal** : Utilisateur
- **Précondition** : L'utilisateur est connecté et un produit est sélectionné
- **Postcondition** : Le produit est mis à jour
- **Scénario nominal** :
  1. L'utilisateur sélectionne un produit
  2. L'utilisateur clique sur "Modifier"
  3. Le système affiche le formulaire pré-rempli
  4. L'utilisateur modifie les informations
  5. L'utilisateur valide
  6. Le système met à jour le produit
  7. Le système actualise la liste

#### CU5 : Supprimer un produit
- **Acteur principal** : Utilisateur
- **Précondition** : L'utilisateur est connecté et un produit est sélectionné
- **Postcondition** : Le produit est supprimé
- **Scénario nominal** :
  1. L'utilisateur sélectionne un produit
  2. L'utilisateur clique sur "Supprimer"
  3. Le système demande confirmation
  4. L'utilisateur confirme
  5. Le système supprime le produit
  6. Le système actualise la liste

### Relations entre Classes

1. **Product** → **Category** : Association (many-to-one)
   - Un produit appartient à une catégorie
   - Une catégorie peut avoir plusieurs produits

2. **userdao** → **dbconnection** : Dépendance
   - userdao utilise dbconnection pour les opérations

3. **productdao** → **dbconnection** : Dépendance
   - productdao utilise dbconnection pour les opérations

4. **logincontroller** → **userdao** : Dépendance
   - Le contrôleur utilise le DAO pour l'authentification

5. **productcontroller** → **productdao** : Dépendance
   - Le contrôleur utilise le DAO pour les opérations CRUD

6. **main** → **logincontroller** : Dépendance
   - L'application principale charge le contrôleur de login
