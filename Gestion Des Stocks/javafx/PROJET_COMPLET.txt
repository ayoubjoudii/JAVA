✅ FONCTIONNALITÉS IMPLÉMENTÉES (100%)
═══════════════════════════════════════════════════════════════════════════════

1. AUTHENTIFICATION ✓
   ├─ Login avec username et password
   ├─ Validation des champs
   ├─ Messages d'erreur clairs
   └─ Compte admin par défaut (admin/admin)

2. GESTION DES PRODUITS ✓
   ├─ Ajouter un produit (avec validation)
   ├─ Modifier un produit (dialog pré-rempli)
   ├─ Supprimer un produit (avec confirmation)
   └─ Consulter tous les produits (tableau interactif)

3. RECHERCHE ET FILTRAGE ✓
   ├─ Rechercher par nom de produit
   ├─ Rechercher par catégorie
   ├─ Filtrer par catégorie (ComboBox)
   └─ Rafraîchir la liste

4. GESTION DES STATUTS ✓
   ├─ Calcul automatique du statut
   ├─ "Rupture de stock" si quantité < 5
   ├─ "Disponible" si quantité >= 5
   └─ Code couleur (rouge/vert)

5. STATISTIQUES ✓
   ├─ Nombre total de produits
   ├─ Valeur totale du stock (prix × quantité)
   └─ Mise à jour en temps réel

📊 BASE DE DONNÉES (MySQL)
═══════════════════════════════════════════════════════════════════════════════

Table: users
├─ id INT PRIMARY KEY AUTO_INCREMENT
├─ username VARCHAR(50) UNIQUE
├─ password VARCHAR(255)
├─ full_name VARCHAR(100)
├─ role VARCHAR(20)
└─ created_at TIMESTAMP

Table: categories
├─ id INT PRIMARY KEY AUTO_INCREMENT
├─ name VARCHAR(100) UNIQUE
├─ description TEXT
└─ created_at TIMESTAMP

Table: products
├─ id INT PRIMARY KEY AUTO_INCREMENT
├─ name VARCHAR(200)
├─ description TEXT
├─ price DECIMAL(10,2)
├─ quantity INT
├─ category_id INT (FK → categories.id)
├─ created_at TIMESTAMP
└─ updated_at TIMESTAMP

DONNÉES PRÉ-CHARGÉES:
├─ 1 utilisateur (admin/admin)
├─ 8 catégories (Électronique, Alimentaire, Vêtements, etc.)
└─ 18 produits exemples (dont 3 en rupture de stock)

🚀 INSTALLATION ET EXÉCUTION
═══════════════════════════════════════════════════════════════════════════════

PRÉREQUIS:
✓ Java JDK 17 ou supérieur
✓ MySQL 8.0 ou supérieur
✓ Connexion Internet (pour Maven)

INSTALLATION RAPIDE (3 étapes):

1. Importer la base de données:
   > mysql -u root -p < database.sql

2. Compiler l'application:
   > cd javafx
   > mvnw.cmd clean package

3. Lancer l'application:
   > execute.bat
   OU
   > mvnw.cmd javafx:run

CONNEXION:
   Username: admin
   Password: admin
